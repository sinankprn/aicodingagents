# Always-On Agents

A 9-slide deck by Sinan Koparan on always-on AI agents: agents with a computer of their own that keep working after you close the app.

1. Title
2. From answers to actions: LLMs that gave text, agents that perform tasks
3. OpenClaw by Peter Steinberger
4. Muse (Meta), Grok Bot (xAI) and dots (OpenAI)
5. What are always-on agents?
6. Benefits: AI as an extension of you
7. What can they do in sport?
8. Data governance: personal vs enterprise accounts
9. Thanks for listening

The slide sources live in `deck/project/`. `deck.json` is the index, and each slide is one file in `slides/` with speaker notes in its `<aside>`. The cover and closing slides carry a small animated layer on top of static diagrams, so the static version still reads correctly when exported to PDF or PPTX.

## Sources

- [Introducing dots](https://openai.com/index/introducing-dots/), OpenAI
- [Introducing Grok Bot](https://x.ai/news/introducing-grok-bot), xAI
- [OpenClaw](https://en.wikipedia.org/wiki/OpenClaw) and [Muse](https://en.wikipedia.org/wiki/Muse_(AI_agent)), Wikipedia
